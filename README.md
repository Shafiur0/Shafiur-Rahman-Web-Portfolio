# Shafiur Rahman - Web Portfolio

This is a premium, modern, and high-performance Web Portfolio built with React Router v7 and server-side rendering (SSR), optimized for speed and SEO.

## Features

- **⚡ Fast Load Times**: Transformed from client-side single-page app (SPA) to fully Server-Side Rendered (SSR) architecture, querying the database before paint.
- **💼 Content Management**: Premium admin dashboard to manage Skills, Projects, Achievements, Certificates, and Profile Information.
- **✉️ Inbox Flow**: Integrated contact section and database message manager.
- **✨ Premium UI**: Responsive layout featuring CSS animations, image zoom, and interactive sections.

## Technology Stack

- **Framework**: React Router v7
- **Database**: Neon (Serverless Postgres)
- **Styling**: Tailwind CSS
- **Deployment**: Vercel

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure environment variables in `.env` (using `.env.example` as a template).
3. Start the dev server:
   ```bash
   npm run dev
   ```
